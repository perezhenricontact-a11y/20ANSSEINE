Site d'invitation : samedi 27 février 2027, renouvellement des vœux à 10 h puis croisière rock'n'roll sur la Seine.

- `index.html` : la page (onglets Invitation, Programme & infos, Trombinoscope, Je réponds, Souvenirs, Surprise) — tout se règle dans le bloc `CONFIG` du script
- `img/` : affiches, photos 2007 / 2017 / aujourd'hui, portraits de marins (`marin-*.jpg`), aperçu de partage
- `img/marins/` : photos de marins des invités reçues par le formulaire photo (une par personne, carrées)
- `media/` : bande-son et carte vidéo
