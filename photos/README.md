# Photos & vidéos du jour J

Déposez ici les photos et vidéos du 20 mars 2027 : elles s'affichent automatiquement dans l'onglet « Photos & vidéos » du site, rangées par album selon le **préfixe du nom de fichier** :

| Préfixe | Album |
|---|---|
| `mairie-` | Événement mairie (renouvellement des vœux) |
| `trajet-` | Événement trajet (voiture de collection) |
| `bateau-` | Événement bateau (croisière sur la Seine) |
| `commemoration-` | Événement commémoration |

Exemples : `mairie-01.jpg`, `trajet-03.mp4`, `bateau-12.jpg`, `commemoration-02.jpg`. Un fichier sans préfixe connu va dans « Autres souvenirs du jour J ».

Formats : jpg, jpeg, png, webp, gif (photos) ; mp4, webm, mov, m4v (vidéos). Préférez des photos réduites (moins de 2 Mo) pour un affichage rapide.

Dépôt : sur GitHub, ouvrir ce dossier `photos`, « Add file » → « Upload files », glisser les fichiers, puis « Commit changes ». Le site se met à jour en une à deux minutes.
